# An Ocean of Borrowed Time

Original AI-assisted artwork created for make.fun's "Make the coolest art" bounty on 13 November 2026 (Malaysia time).

`main.py` copies the included JPEG bytes to `/output/entry.png`. The platform brief accepts a whole JPEG or PNG at that output path. The image is 1024 × 1024 pixels and under 1 MiB. Running the script twice produces identical bytes. The program uses only Python's standard library and makes no network requests.

The source bundle still needs the authentic AI coding-agent transcript required by the bounty and submission through the platform. No entry or prize claim has been made.
